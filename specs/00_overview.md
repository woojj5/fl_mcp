# FL Platform 요구사항 및 문서 안내

## 제품 개요

FL Platform은 중앙 서버가 원본 데이터를 모으지 않고 여러 클라이언트의 로컬 학습 결과를 집계해 전역 모델을 만드는 실험·시연용 연합학습 플랫폼이다. 현재 저장소의 실행 진입점은 대시보드, 분산 서버, 클라이언트 세 가지다.

## 사용자와 핵심 흐름

- 실험 운영자는 데이터셋, 모델, 분할 방식, 학습 횟수 및 집계 전략을 정해 학습을 수행하고 기록을 확인한다.
- 분산 운영자는 서버를 띄우고 여러 클라이언트가 등록·학습·업로드하도록 구성한다.
- 클라이언트는 로컬 데이터로 학습하고 가중치를 서버로 전송하며, 로컬 예측을 제공한다.
- 운영자는 대시보드에서 실험 상태와 배포 노드 상태를 확인한다.

## 기준과 용어

이 문서들은 저장소에서 확인 가능한 `run.py`, `server.py`, `client.py`, `config.yaml`, `docker-compose.yml`, `Dockerfile`, `requirements.txt`, `skills/skill.py`를 기준으로 한다. 파일이나 모듈이 저장소에 없는 경우 구현 완료로 간주하지 않는다. 구성 요소의 내부 구현은 `fl_platform/` 패키지가 현재 트리에 없으므로 일부 검증할 수 없다.

`라운드`는 선택된 클라이언트들이 각자 로컬 학습한 뒤 서버가 결과를 집계하는 한 주기다. `전역 모델`은 서버가 집계해 보관하고 클라이언트에 배포하는 모델이다.
